# 🦅 PokeAPI Viewer

![Astro](https://img.shields.io/badge/Astro-5.0-orange?style=for-the-badge&logo=astro)
![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-3.4-38B2AC?style=for-the-badge&logo=tailwind-css)

Explora el mundo Pokémon en esta aplicación web rápida, moderna y elegante. Diseñada para ofrecer la mejor experiencia de usuario al consultar información de la famosa [PokeAPI](https://pokeapi.co/).

## 🌐 Demo en Vivo

Visita la aplicación funcionando en: **[https://alcaan16.es/](https://alcaan16.es/)**

## ✨ ¿Qué puedes hacer?

Esta aplicación te permite navegar y descubrir detalles sobre tus Pokémon favoritos de una manera fluida e intuitiva.

- **Exploración Rápida**: Navega por la lista completa de Pokémon sin tiempos de espera gracias a la tecnología estática de Astro.
- **Detalles Completos**: Consulta tipos, habilidades, estadísticas y evoluciones de cada Pokémon.
- **Diseño Adaptable**: Disfruta de una experiencia perfecta tanto en tu móvil como en tu ordenador.
- **Interfaz Moderna**: Un diseño limpio y atractivo para que te centres en lo importante.

## 🚀 Tecnologías

Este proyecto ha sido construido utilizando las últimas tecnologías web para asegurar el máximo rendimiento:

- **Astro**: Para una velocidad de carga instantánea.
- **Tailwind CSS**: Para un diseño visualmente impactante y responsivo.
- **TypeScript**: Para garantizar la robustez del código.
